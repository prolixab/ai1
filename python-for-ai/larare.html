Python för AI – elevernas framsteg

Se hur långt varje elev har kommit i övningen och vilka uppgifter som är svårast för klassen.

Från servern

Elevernas framsteg skickas automatiskt till servern (Vercel) och hämtas hit med lärarnyckeln.

Ange lärarnyckeln för att hämta elevernas framsteg.

Så slår du på lagringen
  1. I Vercel: öppna projektet → Storage → lägg till Upstash Redis (gratisnivån räcker) och koppla den till projektet.
  2. Settings → Environment Variables: lägg till TEACHER_KEY med ett lösenord du väljer.
  3. Gör en ny deploy. Kontrollera att api i ovningar.js pekar på Vercel-sajten.

Framstegskoder

Utan server: be eleverna klicka på Min framstegskod och skicka koden till dig. Klistra in en eller flera koder här (en per rad).

Elever

Rätt direkt Rätt efter flera försök Visade svaret Inte gjord Klicka på en elev för att se varje uppgift.

Uppgifter

Andel av eleverna (i urvalet ovan) som klarat varje uppgift, och hur.
